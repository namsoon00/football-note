# Running coach 3D avatar notices

## Reference runner model

`models/reference_runner.glb` is a fixed reference runner assembled from
MakeHuman Community core graphical assets and exported for this application.
Those core graphical assets are available under the Creative Commons CC0 1.0
Universal dedication.

- Source: https://github.com/makehumancommunity/makehuman-assets
- License: https://creativecommons.org/publicdomain/zero/1.0/

The model is a reference avatar only. It is not a reconstruction of a
runner's body, face, clothing, or identity.
